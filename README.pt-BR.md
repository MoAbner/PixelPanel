# Pixel Panel

Um pequeno editor de pixel art feito com HTML, CSS e JavaScript. Pinte uma grade no navegador, escolha cores e baixe sua arte como imagem.

[Experimentar o editor](https://moabner.github.io/PixelPanel/)

## Funcionalidades

- Grade de pixels clicável e seleção de cores.
- Exportação da imagem diretamente pelo navegador.
- Interface focada em experimentos rápidos com pixel art.

## Executar localmente

```bash
git clone https://github.com/MoAbner/PixelPanel.git
cd PixelPanel
```

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript puros; não há etapa de instalação de pacotes.

## O que explorei

Eventos de mouse, renderização em grade, interações com o DOM, geração de imagens e experiência do usuário.
